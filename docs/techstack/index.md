# 技术栈&灵魂伴侣

> 技术栈专题总览 —— 从框架选型到工程实践，构建前端知识体系的全景地图

前端技术栈的选择，不仅关乎开发效率，更决定了项目的长期可维护性与团队协作体验。本专题从**主流框架深度解析**到**横向对比选型**，帮助你建立清晰的技术决策框架。

## 专题结构

| 模块         | 内容                                               |
| ------------ | -------------------------------------------------- |
| **Vue**      | 响应式原理、组合式 API、编译优化、生态工具链       |
| **React**    | Fiber 架构、Hooks 机制、并发模式、状态管理         |
| **Svelte**   | 编译时框架、无虚拟 DOM、Runes 响应式、极简心智模型 |
| **框架横评** | 核心理念对比、性能基准、适用场景与选型建议         |

::: info Info
选框架不是选"最好"，而是选"最合适"。理解每个框架的设计哲学与权衡，才能做出理性的技术决策。
:::

## 为什么叫"灵魂伴侣"？

技术栈与开发者的关系，如同灵魂伴侣 —— 需要**三观契合**（设计哲学认同）、**相处舒适**（开发体验流畅）、**共同成长**（生态持续演进）。盲目追逐热度不如深入理解本质，找到真正适合自己的技术伙伴。
