## 静态站点生成器

- [Jamstack 站点生成器](https://jamstack.org/generators/)

  > Jamstack 站点静态站点生成器列表

- [VitePress](https://vitepress.dev/zh/)

  > VitePress 是一个静态站点生成器 (SSG)，专为构建快速、以内容为中心的站点而设计。

- [Astro](https://docs.astro.build/zh-cn/getting-started/)

  > Astro 是最适合构建像博客、营销网站、电子商务网站这样的以内容驱动的网站的 Web 框架。

- [Fumadocs](https://www.fumadocs.dev/)

  > 漂亮且灵活的 React.js 文档框架。

- [Rspress](https://rspress.rs/zh/)

  > Rspress 是一个基于Rspack的快速静态站点生成器，一个基于 Rust 的捆绑器。 它支持通过 MDX（带有 React 组件的 Markdown） 写作，集成了文本搜索、多语言支持和插件扩展的特性。 用于创建优雅文档和静态网站，Rspress 生成易于部署的静态 HTML 文件。

- [Docusaurus](https://docusaurus.io/zh-CN/docs)

  > Docusaurus 是一款静态站点生成器。 我们释放了React的全部潜能，搭建了这一款有着快速客户端导航与交互性极佳的单页应用。 它不仅提供了开箱即用的文档功能，也可用于搭建各种类型的网站（个人网站、产品、博客、营销主页等等）。

- [Hugo](https://gohugo.io/)

  > Hugo是由Go编写的快速现代静态网站生成器，旨在让网站创建变得有趣。

- [Eleventy](https://www.11ty.cn/)

  > Eleventy 是一个比竞品更简洁的静态网站生成器。

- [VuePress](https://vuepress.vuejs.org/zh/)

  > VuePress 是一个以 Markdown 为中心的静态网站生成器（Static Site Generator, SSG）。

- [Nextra](https://nextra.site/)

  > 用 Next.js 和 MDX 打造漂亮的网站

- [MkDocs](https://www.mkdocs.org/)

  > MkDocs 是一款受欢迎的 Python 静态站点生成器，其设计理念与 Docusaurus 类似。

- [Jekyll](https://github.com/jekyll/jekyll)
  > Jekyll 是一款简单、适合博客的静态网站生成器，非常适合个人、项目或组织网站。
