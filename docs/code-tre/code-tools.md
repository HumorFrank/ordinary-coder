# 程序员工具箱

## AI 编程工具管理

- [CC Switch](https://www.ccswitch.io/zh/)：统一管理 AI Agent 的供应商配置。

## Node.js 版本管理工具

- [nvm](https://www.nvmnode.com/zh/)：nvm（Node版本管理器）是一个允许开发者轻松安装、管理和使用多个Node.js版本的工具。
